ChatGPT / Codex device sign-in

Use the included compose.models.yaml and deploy/litellm.example.yaml to run the optional bridge. Configure a model with LiteLLM's chatgpt/ prefix.

  1. Start the bridge with its own proxy key and a persistent token directory.
  2. Make the first request locally and follow the device URL and code printed by LiteLLM. Complete sign-in yourself.
  3. Add the bridge here with protocol LiteLLM, its API base URL and proxy key. Discover the configured model names.
  4. Select your-prefix/model-name in Hermes or another client.

Sign-in and token refresh are owned by LiteLLM. Toolmux does not import your desktop credentials. Chat Completions support varies by subscription model; Responses is the native protocol.
