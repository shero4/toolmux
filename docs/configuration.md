# Configuration reference

Native Toolmux reads environment variables, with a local `.env` file as a
fallback. `TOOLMUX_ENV_FILE` selects a different file. Compose passes the settings
listed in its `environment` block; adding a variable to `.env` alone does not
automatically inject it into the container.

| Variable | Purpose | Default |
| --- | --- | --- |
| `TOOLMUX_MASTER_KEY` | Base64 encryption key generated by `keygen` | Required |
| `TOOLMUX_DATABASE_URL` | PostgreSQL connection string | Local development database |
| `TOOLMUX_ADDR` | Native listening interface and port | `127.0.0.1:8080` |
| `TOOLMUX_BASE_URL` | Administration URL, cookie security, OAuth callbacks | `http://localhost:8080` |
| `TOOLMUX_GATEWAY_URL` | Advertised tool and inference URL | Administration URL |
| `TOOLMUX_BIND_IP` | Compose host publishing interface | `127.0.0.1` |
| `TOOLMUX_PORT` | Compose host publishing port | `8080` |
| `TOOLMUX_DISCOVERY_ROOTS` | Native discovery roots, separated by the OS path-list separator | Standard locations |
| `TOOLMUX_HOST_HOME` | Read-only host mount for `compose.discovery.yaml` | Set explicitly |
| `TOOLMUX_CODEX_CONTAINER` | Docker bridge used by subscription sign-in controls | `toolmux-models-1` |

Use `0.0.0.0:8080` to listen on all native IPv4 interfaces, or set Compose's
`TOOLMUX_BIND_IP=0.0.0.0` to publish on them. Apply firewall restrictions before
opening access. A specific bind IP must belong to the host. Never use `0.0.0.0`
as a client URL; changing the URL does not change the listener.

For a split deployment, keep the administration URL private and set the gateway
URL to the public HTTPS origin. Upstream OAuth callbacks use the administration
URL. See the [gateway guide](../deploy/GATEWAY.md) for the complete setup.
Restart the native service or recreate containers after changing configuration.

Keep the original master key with encrypted backups. Regenerating it does not
rotate stored credentials: it makes those credentials unreadable. Never commit
`.env`, tokens, database dumps, or installation-specific records.
